=====================================================================
ESPAÑOL
=====================================================================
Windows 10/11: abra MattPad-Windows.msi y acepte la licencia. No se
  necesitan derechos de administrador. Si aparece «Windows protegió su
  PC»: «Más información» → «Ejecutar de todas formas».
macOS 12+: abra el .dmg y arrastre MattPad a «Aplicaciones».
  AppleSilicon = Mac con M1/M2/M3/M4; Intel = Mac más antiguos.
  Primer inicio (la app no está notarizada por Apple):
  macOS 15+: abrir una vez → «Listo» → Ajustes del Sistema → Privacidad
  y seguridad → abajo «Abrir igualmente».  macOS 12–14: clic derecho en
  MattPad → «Abrir» → «Abrir».
Linux: flatpak install --user MattPad-Linux.flatpak
  (o doble clic para abrirlo con «Software» / «Discover»).
El idioma se toma del sistema; se cambia en Herramientas → Idioma.

=====================================================================
PORTUGUÊS
=====================================================================
Windows 10/11: abra MattPad-Windows.msi e aceite a licença. Não são
  necessários direitos de administrador. Se aparecer «O Windows protegeu
  o computador»: «Mais informações» → «Executar assim mesmo».
macOS 12+: abra o .dmg e arraste o MattPad para «Aplicativos».
  AppleSilicon = Mac com M1/M2/M3/M4; Intel = Macs mais antigos.
  Primeira abertura (o app não é notarizado pela Apple):
  macOS 15+: abrir uma vez → «OK» → Ajustes do Sistema → Privacidade e
  Segurança → no fim «Abrir Mesmo Assim».  macOS 12–14: clique direito
  no MattPad → «Abrir» → «Abrir».
Linux: flatpak install --user MattPad-Linux.flatpak
  (ou clique duplo para abrir com «Software» / «Discover»).
O idioma vem do sistema; pode ser alterado em Ferramentas → Idioma.

=====================================================================
ENGLISH
=====================================================================
Windows 10/11: open MattPad-Windows.msi and accept the license. No
  administrator rights needed. If "Windows protected your PC" appears:
  "More info" → "Run anyway".
macOS 12+: open the .dmg and drag MattPad onto "Applications".
  AppleSilicon = Macs with M1/M2/M3/M4; Intel = older Macs.
  First start (the app is not notarized by Apple):
  macOS 15+: open once → "Done" → System Settings → Privacy & Security →
  at the bottom "Open Anyway".  macOS 12–14: right-click MattPad →
  "Open" → "Open".
Linux: flatpak install --user MattPad-Linux.flatpak
  (or double-click to open it with "Software" / "Discover").
The language follows the system; change it under Tools → Interface language.

=====================================================================
DEUTSCH
=====================================================================
Windows 10/11: MattPad-Windows.msi öffnen, Lizenz bestätigen. Keine
  Administratorrechte nötig. Bei „Der Computer wurde durch Windows
  geschützt“: „Weitere Informationen“ → „Trotzdem ausführen“.
macOS 12+: .dmg öffnen, MattPad auf „Programme“ ziehen.
  AppleSilicon = Macs mit M1/M2/M3/M4; Intel = ältere Macs.
  Erster Start (nicht von Apple beglaubigt):
  macOS 15+: einmal öffnen → „Fertig“ → Systemeinstellungen → Datenschutz
  & Sicherheit → unten „Dennoch öffnen“.  macOS 12–14: Rechtsklick auf
  MattPad → „Öffnen“ → „Öffnen“.
Linux: flatpak install --user MattPad-Linux.flatpak
  (oder Doppelklick, öffnet sich in „Software“ / „Discover“).
Die Sprache folgt dem System; ändern unter Extras → Sprache der Oberfläche.
